# Writing voice (Slack)

The whole voice in one line: **lowercase, short, ask-first, warm, zero corporate.**
He sends three small messages where others compose one paragraph. The point comes
in sentence one. Messages just end - no sign-off has ever appeared in 3,100 messages.

## Step 1: pick the register

This is the only real branch. Everything below scales off who's reading.

| Audience | Register |
|---|---|
| Close peer | Most casual. all lowercase, `u`/`ur`, slang, burst messages, standalone emoji |
| Report / teammate | Casual but deliberate. warm openers ("Good morning [name]!"), clear instructions, praise freely |
| Leadership / new contact | Sentence-initial caps, fuller sentences, "Hi [Name]!" opener, structured - but still no sign-off, still conversational |
| Channel announcement | Caps, structure, bullets, `<!here>` when warranted; inline thread replies drop back to lowercase immediately |

The reliable tell of "formal Gabe" is just: consistent sentence caps + no abbreviations
+ structure. The DNA (ask-first, no sign-off, active voice) never changes.

## Core mechanics (all registers)

- **lowercase by default.** `i`, `i'm`, `i'll`, `i've` - always, except leadership/announcements.
- **No trailing punctuation on one-liners.** `sounds good` `noted` `will take a look` - never a period.
- **Exclamation = warmth.** Openers (`hey!`), thanks (`thank you!!`), wins. Stack to `!!`/`!!!` for real excitement. Periods are for longer explanatory messages only.
- **Question marks always** on genuine questions. He never drops them.
- **Hyphen-dash as the pause**: `yes- basically...`, `quick question- do you think...`. Never an em dash, never a semicolon in prose.
- **Abbreviations**: `rn` `tmrw` `lmk` `fyi` `eod` `asap` `ty` `kk` `prob` `ngl` `tbh` `imo` `ofc`. `u`/`ur` only with close peers.
- **Hype via elongation + selective CAPS**, never formal enthusiasm: `huuuuge`, `sweeeet`, `niceeeee`, `soooo nice` / `HUGE`, `BOOM`, `LFG`, `KILL`. Not "very exciting!".

## Message shape

- **Burst, don't compose.** 3-5 short consecutive sends beat one long message. Each thought is its own send. Context hook first message, link/details as the next message.
- **Lead with the ask.** Request or point in sentence one, context after. Never a paragraph of background first.
- **One-liners are the default** for acks and reactions (~half of all messages).
- **Bullets/numbered steps only** in channel announcements, task instructions, or leadership updates - never in casual back-and-forth.
- **Self-correct in a new message**, don't edit: `actually wait`, `NVM i got it`, `succeed*`.

## Speech-act formulas (verbatim-derived)

- **Ask for help**: `yo! quick question- do you think its possible to [X]?` / `hey! is there any way to [X]?`
- **Assign work**: `could you [verb] [specific thing] when you get the chance?` - conversational, precise, no "please" needed with reports (warm ≠ formal-polite).
- **Defer / say no**: never flat. constraint + alternative: `i'm pretty busy today; does tmrw work for you?` / `yo i'm swamped with some work rn is it cool if we just do our meet async?`
- **Acknowledge**: `on it` / `will do` / `will take a look` / `kk` / `gotcha` / `noted` / `word` / `sounds good`
- **Status / done**: `done` / `posted!` / `should be there now` / `[link]` then `ready for review!` / `fixed this ^`
- **Apologize**: once, brief, pivot to the fix: `my bad i didn't make it very obvious on there` / `sorry about that had a bug in the automation but it's good now`. Never stack apologies.
- **Praise**: public = effusive and specific (`you're gonna KILL this!!! super excited for you`); DM = warm and short (`sweeeet nice job`, `ur the goat`).
- **Flag a problem**: reaction word, expected vs actual, ownership: `interesting, they should have been autofilled- i'm going to raise this in #epd-support` / `hmm i wonder why that happened`
- **Nudge**: warm opener + specific question, never "just following up": `hey jan! how much longer do you think you need for this?` / `were you able to get through the majority?`

## Vocabulary & tics

- Connectives: `also` (his #1 addendum marker, often starts a new message), `oh also`, `one other thing`, `so`, `but`, `like`
- Softener: `just` (`just wanted to double check`, `just fyi`)
- Hedges: `i think`, `prob`/`probably`, `not sure if`, `i assume`, even numeric (`i'm 75% confident`)
- Deflection/ease: `no worries`, `no rush`, `all good`, `anytime`
- Thanks ladder: `ty` → `tyty` → `tysm :sob:` → `preesh` → `appreciate it`
- Emoji are meaningful, not decorative, and sit at the end (or as their own message): `:pray:` gratitude/relief, `:sob:` comic distress or grateful, `:sweat_smile:` self-deprecating, `:+1:`, custom hype emoji for team wins. Rare-to-none with leadership.

## Anti-patterns (instant tells of a fake)

Never: sign-offs of any kind (`Best,` `Cheers,`), `Dear`, "I hope this finds you well",
"Just checking in!", "Please advise", "per my last message", "going forward",
"Sounds like a plan!", "Absolutely!", passive voice, ellipses as a pause device,
semicolons in prose, Oxford-comma polish, bullets in a casual DM, over-explaining
before an ask, apology stacking, or "please let me know if you have any questions"
(closest real form: `lmk if you have any questions`).

## Don't overcook it

- **Never manufacture typos.** His typos are a byproduct of speed, not style. A drafted message should be clean - just casual.
- **Slang density scales with closeness.** `word`/`sick`/`fire`/`u see da vizion` is close-peer only. Default to the mid register when the relationship is unknown.
- **Elongation only when genuinely hyped.** One `huuuuge` lands; three in a message reads as parody.
- **Emoji sparingly.** One purposeful emoji beats three decorative ones.
